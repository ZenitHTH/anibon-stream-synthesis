# Activity Categories Reference Taxonomy

Standard categories used in `activity_timeline.json` for on-screen classification:

| Category | Typical Visual Indicators | Preferred Base Tag | Description Guidelines |
| :--- | :--- | :--- | :--- |
| `Gameplay` | 3D in-game world, HUD, combat, exploration, driving, boss battle | `[Gameplay]` (or `[Talk]` if off-topic) | Name specific in-game quest, area, or boss |
| `Menu/Inventory` | Pause screen, character gear, stat allocation, deck builder | `[Gameplay]` / `[Talk]` | Mention setup or build tweaking |
| `Gacha` | Summon animation, banner art, pull screen, rainbow sparks | `[Gacha]` | Mention banner & featured character (no spoilers on win/loss) |
| `Web Browsing` | Browser window, Steam Store, Twitter/X, Reddit, Shopee | `[Talk]` / `[News]` | Note website, store page, or article topic |
| `Video Reaction` | YouTube video playback, trailer, announcement stream | `[Reaction]` / `[WatchParty]` | Name the trailer / video being watched |
| `AFK/Intermission` | Empty chair, "BRB / ไปห้องน้ำ" screen, static standby art | `[AFK]` | Note break / bathroom run when > 2 minutes |
| `Fullscreen Cam` | Webcam enlarged to fullscreen with no game HUD | `[Talk]` / `[Story]` | High-focus discussion, stream intro, or outro |

---

## Webcam Expression Taxonomy

- `neutral` — Normal focused resting face or speech.
- `laughing` — Visible laughing, smiling broadly, hysterics (pairs with `MEME_PULSE`).
- `shocked_facepalm` — Hand on forehead, facepalming, mouth open in disbelief.
- `serious` — Intense concentration or serious editorial monologue.
- `eating_drinking` — Drinking water, sipping coffee, eating snacks.
- `away` — Chair empty, body not visible in frame.
