## Game Systems

### Gacha (ガチャ / ระบบกาชา)
- **Pyroxene (ピロクセン / ไพโรซีน)** — premium currency. 120 per pull, 12000 for spark.
- **Pickup banner — rate-up character. 0.7% for rate-up (base UR rate 3%).**
- **Spark (天井 / เทียนจอย / การ์ดจอย)** — pity at 200 pulls (24000 pyroxene). Can spark target character.
- **Eleph (神名文字 / เอเลฟ / เอเลฟซีน)** — character shards for upgrading star rarity.
- **Recruit (募集 / รับสมัคร)** — gacha banner. Limited = event exclusive.
- **F2P income (~12000 pyroxene/month endgame)** — controversial, nerfed over time.
- **Recent drama (2026):** JP version changed gacha rates mid-run. 10-pull guarantee rate adjusted without notice. Community angry. Nexon Japan blamed.
- **Nexon gacha controversy** — widespread history of predatory gacha across multiple Nexon titles (MapleStory, Maplestory M, etc.). Boat critiques this extensively.
- **CN gacha model comparison** — Blue Archive JP changed to CN-style low-spark-multiple-pity system. Boat argues this removed excitement.

### Total Assault / Raid (総力戦 / จู่โจมรวมพลัง)
- **Monthly boss rotation** — 6+ difficulties (Normal to Torment/Lunatic).
- **Bosses:** Binah, ShiroKuro, Hieronymus, Hod, Goz, Kaiten, Perorodzilla, Gregorious, Kurokage, etc.
- **Insane (Insane/เกราะบ้า)** — highest difficulty, one-team clear.

### Joint Firing Drill (合同火力演習)
- 3-team mode with special gimmicks each season.

### Grand Assault (大決戦)
- 3-boss gauntlet, pick one to fight, harder version.

### Decagrammaton (デカグラマトン)
- Endgame mode with unique mechanics.

### Momotalk (モモトーク / โมโม่ทอล์ค)
- Character bonding, chat-style interactions, affection system.

### Cafe (カフェ / ร้านกาแฟ)
- Furniture placement, generates currency, invite students.

### Scrimmage (特別授業)
- Character growth stage grinding.
