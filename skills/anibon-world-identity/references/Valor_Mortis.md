# Valor Mortis (แวเลอร์ มอร์ติส) — Knowledge Base

## 🔥 สถานะเกมและข้อมูลสรุป (Game Snapshot)
- **Title**: *Valor Mortis* (แวเลอร์ มอร์ติส) — First-Person Action Soulslike RPG by **One More Level** (creators of *Ghostrunner*), published by **Lyrical Games** (Released October 13, 2026; PC / PS5 / Xbox Series X|S, Day 1 on Xbox Game Pass).
- **Setting**: Alternate 19th-century Europe during the **Napoleonic Wars** plagued by the **Crimson Plague** and **Nephtoglobin**.
- **Protagonist**: **William Dowsett** (วิลเลียม ดาวเซ็ตต์), a resurrected soldier of Napoleon's *Grande Armée*.
- **ASR Phonetic Traps**: `"V Mortis"` / `"verer mortis"` / `"วาเลอร์ มอร์ติส"` → **Valor Mortis**; `"แพี่"` / `"แครี่"` / `"แฮี่"` → **ปัดป้อง / แพรี่ (Parry)**; `"โพส"` / `"โพย"` → **ค่า Posture**; `"ไอฟame"` → **i-frame**; `"Flade Zero"` / `"F zero"` → **Phantom Blade Zero**; `"disorderer"` → **Dishonored**.

## Core Mechanics & Items

| Term | Thai Name | Description |
|------|-----------|-------------|
| **Posture** | ค่า Posture / โพสเจอร์ | Enemy stagger gauge broken by parries and heavy attacks |
| **Parry / Block** | แพรี่ / ปัดป้อง | Timed parry breaks posture; blocking mitigates damage with rally-heal recovery |
| **Nephtoglobin** | เนฟโทโกลบิน | Supernatural mana/resource fueling left-hand Transmutations and traversal |
| **Transmutations** | พลังแปรธาตุ (มือซ้าย) | Off-hand supernatural skills: Fire (flame burst), Stasis (slow/freeze), Shield, Nephtoglobin Grapple |
| **Ferrofluid Flasks** | ขวด Ferrofluid | Healing flasks upgradable across chapters |
| **Catalysts** | แคทาลิสต์ | Currency dropped by enemies for upgrades at Lantern checkpoints |
| **Ambers** | อำพัน (Ambers) | 29 passive build modifier slots (e.g., *Bottomless Well*, *Iron Grip*, *Sleight of Hand*) |
| **Melee Weapons** | อาวุธประชิด | Saber, Rapier, Cutlass, Claymore |
| **Firearms** | อาวุธปืน | Flintlock Pistol, Blunderbuss, Musket (weak-point hits, stagger, special rounds) |

## NPCs & Regions

- **William Dowsett** — Protagonist, resurrected soldier of the *Grande Armée*.
- **Emperor Napoleon Bonaparte** — Voice guiding/binding resurrected soldiers.
- **Louis** — Runs **Louis's Laboratoire** inside the **Abandoned Church** hub to upgrade Transmutations.
- **The Shrike** — Rebel/resistance figure.
- **Regions / Chapters**: The Battlefield (*Ch.1 Revival*), Valley of Ashes (*Ch.2 Regroup*), Abandoned Church (Hub), Fallen Village (*Ch.3 Rendezvous*), Caverns (*Ch.4 Dark Descent*), Vale of Wrath (*Ch.5 Crime*), Cursed Hollow, The Outskirts, University.
