## Core Mechanics

- **Posture ( posture / โพสเจอร์)** — break enemy posture to land deathblow. Core combat loop.
- **Parry / Deflect (パリィ / ปัดป้อง)** — press block at right moment. Parry window ~12 frames (0.2s). Stricter than Dark Souls.
- **Deathblow (忍殺 / จบสังหาร)** — execute enemies with broken posture. One-hit kill on most enemies.
- **Resurrection (復活 / ฟื้นคืนชีพ)** — can revive once per death (reset at bonfire).
- **Shinobi Prosthetic (忍義手 / แขนกล)** — tools: shuriken, firecracker, loaded spear, axe, umbrella, etc.
- **Grapple hook (鈎縄 / ตะขอเกี่ยว)** — vertical traversal.
- **Stealth (忍び / แอบ)** — backstab deathblow from behind.
- **Dragonrot (竜咳 / โรคมังกร)** — NPCs get sick from repeated deaths.
- **Mikiri Counter (見切り / มิคิริ)** — counter thrust attacks by dodging into them.
- **Lightning Reversal (雷返し / สะท้อนสายฟ้า)** — catch lightning mid-air and throw back.

## Story / Setting

- **Sekiro (隻狼)** — the one-armed wolf, protagonist (Wolf / 狼).
- **Kuro (九郎)** — the Divine Heir, Wolf's young master.
- **Isshin Ashina (葦名一心)** — founder of Ashina, final boss.
- **Genichiro Ashina (葦名弦一郎)** — main rival, nephew of Isshin.
- **Emma (エマ)** — physician, ally.
- **Sculptor (仏師)** — former shinobi, carves Buddha statues.
- **Divine Realm (源の宮)** — endgame area.
- **Ashina Castle (葦名城)** — central hub area.
- **Fountainhead Palace (源の宮)** — optional area, lightning reversal required.
- **Shura (修羅)** — bad ending path.

## Boat's Comparison Context

Boat uses Sekiro as the gold standard for parry-based combat. When reviewing games like Dinoblade, he compares:
- Parry window fairness (Sekiro clearer)
- Animation readability (Sekiro more telegraphed)
- Camera quality (Sekiro better locked-on camera)
