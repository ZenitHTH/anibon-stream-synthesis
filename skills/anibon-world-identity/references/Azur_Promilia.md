# 🌟 Azur Promilia (อาซูร์ โพรมีเลีย / 蓝色星原：旅谣) - Knowledge Base

คู่มืออ้างอิงข้อมูลเกม **Azur Promilia** พัฒนาโดย Manjuu Games (ผู้สร้าง Azur Lane) สำหรับใช้ประกอบการทำไทม์สแตมป์สตรีมช่อง Anibon Official

## 🎮 ระบบเกมเพลย์และมุมมองของคอมมูนิตี้

* **ระบบคู่หูสิ่งมีชีวิต (Kibo):** ผู้เล่นสามารถจับ เลี้ยงดู ขี่เดินทาง และร่วมต่อสู้ไปกับเหล่ามอนสเตอร์คู่หูคล้ายระบบสัตว์เลี้ยง/Pal
* **ระบบสร้างบ้านและทำฟาร์ม:** มีระบบบริหารจัดการพื้นที่ ฟาร์มผลผลิต และคราฟต์ไอเทม
* **มุมมองของปู่โบ๊ต:** 
  - ให้ความเห็นว่าตัวเกมมีความเป็น MMO และเน้นการสำรวจ/คอสเมติกสูง ซึ่งส่วนตัวปู่โบ๊ตไม่อินกับแนว MMO เท่าไหร่
  - ประเด็นผู้ให้บริการ PlayPark: ปู่โบ๊ตมองว่าบริการไม่ได้แย่ (จากประสบการณ์เล่น Elsword) แต่ความสำเร็จขึ้นอยู่กับคุณภาพของตัวเกมและระบบกาชาของผู้พัฒนาเอง
