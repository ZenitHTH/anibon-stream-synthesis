# อาเธอเรีย เพนดรากอน (Artoria Pendragon / Saber / Lord Logres)

- **Franchise / Domain**: *Fate/stay night*, [[fate-grand-order]], และคอลแลบ [[honkai-star-rail]] 4.4
- **Role**: ราชาอัศวินคลาส Saber (และร่างแยก Lartoria / ลอร์ด โลเกรส [Lord Logres] ใน FGO)

## Summary of `ปู่โบ๊ต`'s Commentary & Sentiment
- **บทบาทเด่นในคอลแลบ HSR x Fate**: `ปู่โบ๊ต` ติดตามความเคลื่อนไหวตั้งแต่หน้าตู้กาชาเซเบอร์ใน [[honkai-star-rail]] 4.4 ชมคัตซีนผู้บุกเบิกร่วมมือกับเซเบอร์ ฉากปะทะกับกิลกาเมช (พร้อมแซวมุกชุดเกราะเปิดหลัง) การพบกันของเซเบอร์กับโทซากะ ริน จากต่างเส้นทางเวลา และฉากรินใช้ตราบัญชาสั่งเซเบอร์ปลดปล่อยโฮกุปราบบอสอิชตาร์
- **ความเคลื่อนไหวและเมต้าใน FGO**: ใน [[fate-grand-order]] ทั้งลุย Challenge Quest *Fairy Dance* ที่ต้องสู้กับ Lartoria และ Merlin ติดตามบัฟเสริมแกร่งของ Saber Artoria รวมถึงประทับใจร่าง **ลอร์ด โลเกรส (Lord Logres)** ที่รีวิวความคุ้มค่าคู่กับระบบ Class Score และนำไปทดสอบฟาร์มร่วมกับโก๊ะ จนบ่นยับที่เกมไม่ยอมรีรันตู้ Lord Logres เพราะอยากปลดให้ถึง NP4
