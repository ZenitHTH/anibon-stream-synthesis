# FGO Knowledge & Naming Conventions

## 1. Character Naming Rules in Timestamps

### Rule A: New Character Reveals / Banner Introductions
When a **brand new Servant** is revealed, previewed, or released on a new banner:
- Format: `[Thai Transliteration] (English / 日本語)`
- Example: `อัสคาลาพอส (Ascalaphos / アスカラポス)`
- Example: `อาซูมิ อิโซระ (Azumi Isora / 阿曇磯良)`

### Rule B: Familiar Servants, Story Reading, & Gameplay Analysis
For **established/familiar Servants**, ongoing story analysis, or routine gameplay:
- Use the **familiar Thai community name/nickname** only.
- Do **NOT** append `(English / 日本語)` in parentheses.
- Example: `มาชู` (NOT `มาชู (Mash Kyrielight / マシュ)`)
- Example: `ก๊อดดอฟ` (NOT `ก๊อดดอฟ (Goredolf / ゴルドルフ)`)

## 3. Story, Event & System Context Shortcuts

- **Grand Servant Slots & Grand Score:** ระบบปลดล็อกสล็อต Grand Servant และสะสมคะแนน Grand Score เพื่อเพิ่มตัวคูณสเตตัสและคำสั่งพิเศษเฉพาะคลาส Grand (**หมายเหตุ ต.ค. 2026:** สล็อต Extra Class ขยายเพิ่มจาก **2 → 4 ช่อง** หลังจบ *Grand Substitute Battle: Tamamo Aria*)
- **Grand Substitute Event (`冠位名代戦`):** ด่านและอีเวนต์ทดสอบ/เรดระดับสูงเฉพาะทาง (เช่น Ciel และล่าสุด **Tamamo Aria** ต.ค. 2026 ที่บังคับทีม Extra Class ล้วน) เพื่อขยายสิทธิ์ Grand Class
- **11th Anniversary (`Chaldea Academy Festival`, ส.ค. 2026):** ฉลองครบรอบ 11 ปี เปิดตัว **Hassan-i Sabbah (Azrael)** [Assassin 5★ Arts ST], **ขยายเพดาน Bond Lv. 15 → 16**, **เพิ่มเพดาน Fou เป็น 3,000**, เพิ่มดันเจียนถาวร **Azrael's Temple** และแคมเปญ Strengthening Part XX (14 ตัวละคร)
- **Summer 2026 (`Majimun Island` / `カルデア南海大決戦！`, ส.ค. 2026):** อีเวนต์ฤดูร้อนบนเกาะทางใต้ Wave 1 (**Beni-Enma Berserker**, **Kingprotea Moon Cancer**, **Biscione Caster**), Welfare (**Habetrot Pretender** ขับหุ่นยักษ์) และ Wave 2 (**Lilith Rider**, **Kingprotea Alter Avenger**, **Ono-no-Komachi Archer**)
- **35M DL & Halloween 2026 (`Drop Dead! Pumpkin Farm Slaughter`, ก.ย. 2026):** แจกตั๋ว 4★ ฟรี 130 ตัว + 30 SQ (2–16 ก.ย.) ตามด้วยอีเวนต์ฮาโลวีนเปิดตัว **Daedalus** (Berserker 5★ Buster AoE สายซัพลด CD), คอสตูม 6 ตัว และบัฟสกิล **Shuten-Dōji (Caster)** + **Kashin Koji**
- **Waxing Moon Rerun & Dramalogue (ต.ค. 2026):** รีรันคอลแลป *Fate/Samurai Remnant* พร้อมบัฟ **Miyamoto Musashi (Saber)** (+30% NP, บัฟ Buster, OC+2) และแคมเปญละครเวที **FGO THE DRAMALOGUE** (30 ต.ค., ตู้ 29 ตัวรวม U-Olga Marie)
- **Worldwide 100M DL Celebration (พ.ย. 2026):** แคมเปญ 100 ล้านดาวน์โหลดทั่วโลก (7–20 พ.ย.) แจก**ตั๋วเลือก 5★ (SSR) ฟรี 43 ตัว** ถึงบท Ordeal Call II (เงื่อนไข Lv. 60 + Bond 5 ภายใน 31 ธ.ค. 2026) + 30 SQ + ตู้ **Merlin** & **Lady Avalon**
- **Midwinter Swimsuit Special: GUDAGUDA Puni-Puni Wars (พ.ย. 2026 - LIVE):** อีเวนต์ฤดูหนาวชุดว่ายน้ำใน Singularity **GUNMA** (11 พ.ย.–2 ธ.ค.) เปิดตัว **Himiko & Iyo** (5★ Pretender), **Saika Magoichi** (4★ Rider), **Matsunaga Hisahide / Danjo** (4★ Berserker แจกฟรี สายระเบิดพลีชีพ + ทอยเต๋า D20) และคอสตูม **Takasugi Shinsaku** พร้อม **Pickup 2** (13 พ.ย.) & **ด่านเรด** (14 พ.ย.), QoL หน้า Spoils และการแบ่งหน้าจอ Angel's Bazaar
- **Caster Class Skill Update & Mahoyo:** การปรับปรุงสกิลกดคลาส Caster และกระแสการรอคอยความร่วมมือตัวละครจาก Mahoyo (Witch on the Holy Night)

## 4. Common ASR / Whisper Phonic Traps in FGO

- `อ้า` / `Aza` → ตรวจสอบบริบทก่อนสรุป: ถ้าเกี่ยวกับการ์ด/ทีมสีฟ้าคือ **"การ์ด Arts"**; ถ้าพูดถึงสกิล/ดาเมจ/คู่ `ชิเอล` หรือแชทพิมพ์ `ออก้า` คือ **"ออลก้า มารี (U-Olga Marie)"** (`อ้ามารี่`)
- `เคีย่า` / `Kiya` → ถอดเสียงเพี้ยนมาจาก **"คิอาระ (Kiara)"**
- `แกรนด์เอโก้` → คลาสพิเศษ **Grand Ego** (Tamamo no Mae)
- `พูนิพูนิ` / `ปุนปุน` / `ปูนี่ปูนี่` → ถอดเสียงเพี้ยนมาจาก **"ปูนิปูนิ (GUDAGUDA Puni-Puni Wars)"**
- `อิโย` / `อีโยะ` → ถอดเสียงเพี้ยนมาจาก **"อิโยะ (Iyo / 壱与)"**
- `ฮิมิโกะ` / `อิโยะ` → คู่เซอร์แวนท์ **Himiko & Iyo (卑弥呼＆壱与)**
- `มัตสึนางะ` / `ดันโจ` → **Matsunaga Hisahide (松永久秀 / Matsunaga Danjo)**
- `ไซกะ` / `มาโกจิ` → **Saika Magoichi (雑賀孫一)**
- `ทามาโมะ อารียะ` / `อาเรีย` → **Tamamo Aria (タマモアリア)**
- `ไดดารอส` / `เดดาลัส` → **Daedalus (ダイダロス)**
- `อัสราเอล` / `อาซราเอล` → **Hassan-i Sabbah / Azrael (アズライール)**
- `อูลูร์` / `เอิร์ท` / `เอิด` → **Urðr (ウルズ / Doomsday Archer)**
- `บอนด์สิบหก` / `บอน 16` → **Bond Level 16 (ระบบเพดานบอนด์ใหม่ครบรอบ 11 ปี)**
- `ไอออน เอเมอร์ซอส` → **ไทฟอน เอเฟเมรอส (Typhon Ephemeros)**
- `ชูจิโร่` / `โชูโร่` / `Shujiro` → **ชิซึกิ โซจูโร่ (Shizuki Soujuurou)**
- `เซียงเซียง` / `เซียงอยู่` / `เสี้ยงอยู่` → **เซี่ยงหวี่ (Xiang Yu)** (สังเกตบริบทเมคา / เมียลูกพี่อวี่)
- `ตาล็อค` / `ทาล็อค` / `ตารอก` → **ทลาล็อค / เทนอชทิตลัน (Tlaloc / Tenochtitlan)**
- `อัสเล` / `อสเล` (`Asriel`) → **อัซราเอล (Azrael / Hassan-i Sabbah)** (อย่าแปลสลับกับตัวละคร Undertale)
- `เกนไซต้า` → **คาวาคามิ เก็นไซ (Kawakami Gensai)**
- `ด่าน 111` → **ด่าน 1-1-1** (โหนดฟาร์มมอนสเตอร์ 1-1-1 ตัวต่อเวฟ)
- `Common Code` / `คมโค้ด` → **Command Code**; `Butter Brave Chain` → **Buster Brave Chain**
- `เซเว่นชาย` → **เซอร์แวนท์ชาย**
- `เมียงู` → **บิสชิโอเน่ (`Biscione`, Summer 2026 4★ Caster)** (ห้ามคงคำว่า `เมียงู` ดิบในผลลัพธ์)
- `ไอนโก` / `ไซone go` / `ซีอนโก` (`Ziongo`) → **มัตสึนางะ ฮิซาฮิเดะ (`Matsunaga Hisahide`, `นายเก่าดันโจ` / NPC Boss; ยังไม่มีใน `atlas_fgo.db`)**
- `คิมิโกะ` → **ฮิมิโกะ (`Himiko`)**
- `น้ำโนบุ` / `น้ำทอง` / `สลม` → **สไลม์โนบุ / สไลม์โนบุทอง (`Slime Nobu` / `Golden Slime Nobu` Raid)**; `น้ผี` / `น้ำผี` / `นักผี` → **บอสหน้าผี / กระดูก (`Ghost / Skull Nobu`)**
- `เรดโนอา... แลกเกินไป` / `เรท Noah` → **เรดโนอา (`Raid Noah`) ที่แล็ก (`lag`)** (ไม่ใช่ "แลกของ")
- `Butter Brave Change` / `คมคมาโคร` / `คนมาโค` → **Buster Brave Chain (Face Card)** / **Command Code**
